# Результаты

## Последний полный проход

SmolLM2-135M-Instruct, pointer-head 256, полное дообучение decoder в FP32 master weights с BF16 activation compute. Обучение продолжено с более раннего выбранного чекпойнта, optimizer создан заново.

Конфигурация: seed 4118; 1 875 updates по 8 уникальных командам; два порядка кандидатов для consistency loss; CE + 0,1 paired KL; AdamW с weight decay 0,01; LR decoder 2e-6 и головы 1e-5; warmup 20 updates и cosine decay до 25% начального LR. Best выбирался по цене ошибок, где ложное действие при пустом эталоне стоит 5, остальные ошибки — 1.

| Показатель | Результат |
|---|---:|
| Train | 14 847 / 15 000 exact (98,98%) |
| Ложное действие на train | 8 / 7 075 пустых эталонов (0,113%) |
| Последний development checkpoint, matched-сравнение | 909 / 1 000 exact (90,9%) |
| Ложное действие на development | 12 / 500 пустых эталонов (2,4%) |
| Обновления / предъявления | 1 875 / 15 000 уникальных команд |
| Время run | 6 301 с (105,0 мин; включает validation и логирование) |

Высокий train-fit не является оценкой пользовательской точности: корпус синтетический, а development accuracy ниже. Выбор checkpoint по цене ошибок оставил исходный шаг 0 как BEST (88,95% на двух порядках; FAR 1,6%). `last.pt` — именно последнее обученное состояние после полного прохода; его полный train и matched development измерены отдельно. Эти два checkpoint нельзя подменять друг другом.

## Original Rev и наша версия

Обе модели получили те же 1 000 development-команд, инструкцию, кандидатов и фиксированный порядок вариантов. Original Rev — опубликованный Qwen3.5-4B Rev adapter без дообучения на этих командах. Наша версия — SmolLM2-135M с обученным pointer-head и последним full-pass checkpoint.

| Метрика | Наша Smol + Rev head | Published Original Rev |
|---|---:|---:|
| Exact status + tool + arguments | **90,9%** (909/1000) | 73,4% (734/1000) |
| Ложное действие при пустом эталоне | **2,4%** (12/500) | 41,4% (207/500) |
| Batch-1 latency p50 | **67 мс** | 431 мс |
| Batch-1 latency p95 | **70 мс** | 517 мс |
| Peak allocated GPU memory | 2 771 МиБ | 8 144 МиБ |
| Serial batch-1 запросов/с, оценка `1 / p50` | **14,85** | 2,32 |

Парные исходы: обе верны — 660; верна только наша — 249; верен только Original Rev — 74; обе ошиблись — 17. Наша модель быстрее по p50 примерно в 6,4 раза. Запросов/с — обратная величина измеренной latency p50, а не отдельный saturated-throughput прогон параллельных запросов.

Latency измерена на NVIDIA GeForce RTX 5060 Ti (PyTorch 2.11.0+cu128), batch 1, 5 прогревов и 30 повторов с CUDA synchronization. Время включает сборку tensor batch и модельный forward после токенизации, без загрузки модели, токенизации, HTTP и приложения. Это настольное GPU-измерение, не скорость на Wear OS.

## Как читать сравнение

Это сравнение двух готовых систем: модели отличаются размером, tokenizer, pretraining и историей обучения. Поэтому числа не изолируют эффект одной архитектурной детали. Набор синтетический и development-уровня; sealed test и внешний корпус не оценивались. Результаты не являются production accuracy и не доказывают безопасность автоматического выполнения действий.

Полные метрики, per-candidate разбиение, latency samples, hardware, seed и ограничения лежат в `results/matched_comparison.json`. Полный отчёт обучения — `results/training_report.json`; полная оценка всех 15 000 train-команд — `results/full_train_metrics.json`.
